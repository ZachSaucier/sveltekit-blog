I use Cursor daily at work. It's been great!

This past month I decided to purchase the most basic, $20 / month plan for Cursor to do some work on my personal projects.
 
Here's a list of things that I accomplished using the $20 / month plan in my (very) limited free time:

<span class="excerpt_marker"></span>

- Migrated my blog from Svelte 4 to Svelte 5
- Added AT Protocol / Bluesky support to my blog
- Fixed some minor bugs in my blog
- Cleaned up some AWS resources that I had trouble deleting manually
- Fixed the local development for my Just Read server
- Split the *massive* file with all of the Just Read server logic in it into small, purpose-driven, digestible files
- Set up email automations for Just Read, hosted on AWS
- Fixed some security vulnerabilities in the Just Read server
- Added a build script for WebKit and Gecko for Just Read
- Split the *massive* file with most of the Just Read extension logic in it into small, purpose-driven, digestible files
- Added support for editing already-shared pages to Just Read Premium
- Fixed some minor bugs in the extension
- Improved the date, author, and title selection in the extension

After all of this, I had only spent 14% of my total monthly Cursor model allowance and 0% of my other model allowance! That's crazy to me.

- Debugged and fixed my ALB sitting in front of my elastic beanstalk instance went down
- Audited how I could be saving money with my AWS application and saved ~$37 monthly (which is about 75% of my AWS bill).
- Had it upgrade my dependencies to the latest.

19% used

- Swap from [Subsonic](/blog/subsonic/) to [Navidrome](https://www.navidrome.org/) for my self-hosted music libary (I wrote a short [blog post](/blog/navidrome) about this).
- Set up [Immich](https://immich.app/) for analyzing and categorizing our family photos locally.

21% used
